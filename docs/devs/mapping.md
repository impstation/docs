# Mapping Checklist

<WipHeader/>

Taken from https://github.com/impstation/imp-station-14/issues/2611

# Jobs

* Command Jobs: Map command member spawns on the bridge together, ideally in a conference room if one is available.

* Hospitality Director: Map spawn with other command. Head of service department. 1 job slot.

* Courier: Map spawn in mail room. Member of supply department, delivers mail. 1 job slot per map, outside of special circumstances.

* Supply Assistant: Map spawn in cargo alongside cargo technicians. Intern job for supply. 1 job slot per map.

* Research Assistant: This is an upstream role, however with changes we have made to them and scientists, these should be limited to 1 job slot per map.

* Brigmedic: Map spawn in brigmedic or secoff locker room in security. Tends to inmates' medical needs. 1 job slot per map.

# Antags

* Mid-round antag spawn location: Map in publicly accessible but isolated locations, such as maints. Ensure these rooms are escapable. Used by fugitive and paradox anomaly spawns, heretic return from hell system.

# Rooms

* EVA storage: Standard upstream map feature, however we have standardized this room to be Command access locked. Avoid using the EVA airlock prototypes.

* Service storeroom/breakroom: Service access locked room. Should contain the service techfab, servicer cargo ordering console, and a service lockbox. Other contents optional, such as service supplies (cleaning supplies, seeds, etc.), breakroom accoutrements, such as a table, chairs, snacks, microwave.

* Hospitality Director's office/quarters: Hospitality Director access locked room. Map around service area and storeroom. Ideally public-facing, but may be mapped in maints. Should at minimum contain an Oswald spawner, HD bedsheet (thief steal targets), and a filled hospitality director's locker. Otherwise should have design similar to other heads' offices, but service themed.

* mail room: Courier access locked room. Part of the supply department. Must contain a mail teleporter and at least one filled courier locker.

* brigmedic room: Area in security used for treating inmates' medical needs. Locked by security access, if it can be adjacent to a public area, can also be locked by a security/medical airlock for medical doctors to enter if needed. Should contain filled brigmedic locker, a bed (medical, optionally), other medical supplies, medical records computer, morgue unit, stasis bed (optional).

* evidence storage room: Optional, but nice to have. Security access locked room. Area dedicated to keeping confiscated items and other evidence outside of the armory. Utilize evidence lockers and contraband storage crates, mark with evidence sign.

* drone/materials room: Standard upstream mapping feature, but should contain one (maximum) cyborg recharging station drone spawner.

# Machines

* shipyard console: Used by the quartermaster to order shuttles. Map in the QM's office. A spare board can be found in the QM's locker.

* cutter machine: Upstream machine. Used to craft tiles not craftable with the construction menu. Map in public, utility area, such as the tools room. Optional, but nice to have mapped, can otherwise be constructed roundstart with a machine board printed at science.

* washing machines: Functionality not currently implemented, but intended to be used for dying clothing. Map in places where you'd expect to find washing machines such as dorms, restrooms, or other public utility area.

* SalvDrobe: Used for dispensing salvage clothing. Map in salvage.

* Pride-O-Mat: Upstream vendor, but not utilized on all Wizden maps. Map alongside ClothesMate and WinterDrobe, typically in dorms.

* service techfab: Used for constructing service-related supplies. Map in a service access locked area, such as the service storeroom, along with a small amount of materials. Departmental techfabs for all departments eventually (TM).

* Medical/Criminal/Station records computers: We have added functionality to these computers, at least one each should be placed in the appropriate departments.

* oven and food-o-mat: Microwave recipes have been broken up and distributed between the microwave and these two other machines. Map in the kitchen.

* medical assembler: Previous medical microwave recipes must not be produced with this machine. Map in medical.

* book return teleporter: Spawns in random books periodically with the chance of them being tool spellbooks. Mapped in the library ideally behind Librarian access.

# Other entities

* Random HoS gun spawner: The typical standard for the HoS's secondary weapon is a WT550 mapped in their office with two extra magazines. This can optionally be replaced with the random HoS gun spawner, which spawns a random gun case of particular guns, including the WT550.

* Guidebookshelf: Contains easy access to guidebooks. Place at least one in the library.

* griffy suit locker: Contains the Griffy mascot costume. Should be placed in the warden's office where possible.

* janitor's locker: Replacement for the standard custodial closet, locked by janitor access. Contains the Shining Spring (and potentially other janitor-specific toys in the future) along with the regular supplies that were in the custodial closet. Place in janitor's room. Limit to 1 per map.

* station beacons for solars: We have direction-specific prototypes for station beacons. These should be utilized instead of the generic solars station beacon.

# Accesses and doors

* shipyard external airlock: Unlocked external airlock. Shuttles purchased from the shipyard console will prioritize docking with these airlocks, otherwise, they will try to dock with another available external airlock. Use in places where you would prefer shipyard shuttles to spawn.

* vault door: Command access locked door that begins the round bolted. Command door remote must be use to unbolt it. Use for entrance to the vault.

* Logistics doors: Used on cargo shuttles to lock access to the shuttle controls from non-cargo technicians.

* Librarian and Reporter doors: The librarian backroom should be locked behind a librarian access locked door. Reporter's areas can be locked behind reporter access doors.

* Clown, Mime, and Musician doors: Use of doors locked by these accesses is optional, otherwise theatre access locked doors can be used.
