# Creating a Feature Proposal

If you want to create a larger feature for Impstation and need a place to put a design proposal, you are free to use this site to do so.

See the [Site Contributing Guide](../main/docs-contributing.md) to learn how to create pages on this site.

You may optionally choose to use our [Feature Proposal Template](template).

Once you've got your feature proposal ready, you can submit a PR to this site's repository adding it to `docs/feature/Proposals` as a `.md` file.

**Note that a feature proposal being on this site is not an implicit guarantee that it will be approved on Impstation**. This site exists for anyone to use to store ideas, and should not be treated as a roadmap for upcoming features.
