## Associated PR(s)

## About The Feature
> Get more details on the page (but not too many details!). Talk a bit about what this feature might look and feel like.

### Desired Gameplay
> Explain the *kind* of gameplay and mechanics we want to see in the game area's design. Don't get too granular: list some of the main ways you want players to engage in your feature, and why they're important. Dot point format is great for this.

### Undesired Gameplay
> Similar to "Desired Gamplay", but instead listing easy pitfalls and directions we *don't* want the game area to move in. This sets boundaries and helps achieve cohesion when designing new aspects of an area.

## Reasoning
> Why do you want this feature to exist? What does it add to the game? Can be as simple as 'for fun' if you want. However, a strong feature proposal may talk about current problem areas in the game.

### Considered Alternatives
> Have you considered any alternative ways that this feature could address a problem you've identified? Why do or don't those alternatives work? List them here, and talk about your approach!

### Balance
> Will this have any impact on gameplay balance? How might you mitigate that? Or is it intentional?

## Technical Implementation
> If this feature will necessitate a lot of work on the technical side (mass-editing .yml files, new sprites, updating maps, new documentation or guidebook pages, etc.), note it down here.
